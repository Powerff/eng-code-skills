# 后端评审优化 示例

[English](./basic.md) · [中文](./basic.zh-CN.md)

## 场景
演示从 Cursor `code-optimize` 封装而来的后端工作流技能。

## 输入

```text
对当前后端变更/问题启用 backend-code-optimize。
遵守项目既有约定。输出必须含风险警告与人工校验清单。
```

## 期望产出要点

```text
- 按技能阶段顺序执行
- 给出有证据支撑的总结
- 包含风险警告 + 人工校验清单
```

## 说明
先评审再落地，保持行为不变的结构优化。
