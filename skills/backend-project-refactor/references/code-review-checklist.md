# 后端重构 CR 清单（节选）

## 设计
- [ ] 依赖方向单向（入口 → 编排 → 领域 → 基础设施）
- [ ] 领域模型不依赖协议/框架类型
- [ ] Repo/ACL 通过接口隔离

## 实现
- [ ] 错误处理规范，不吞异常
- [ ] 日志含 trace/request id
- [ ] Context/超时全链路透传
- [ ] 锁/事务边界与方案一致

## 规范
- [ ] 命名/注释符合仓库范式
- [ ] 无方案外的「顺手优化」改变语义

## 完整性
- [ ] 归属映射逐步有对应代码
- [ ] 状态机分支全覆盖或已记录废弃决策
- [ ] GAP 项已关闭或显式延期
